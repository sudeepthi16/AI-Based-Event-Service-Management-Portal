# AI-Based Event & Service Management Portal

## Project Overview
The **AI-Based Event & Service Management Portal** is a web-based application designed to simplify event planning and provide access to various online services through a single platform.

It combines event design features, service operations, workflow management, and analytics in one application.

## Key Features

- **Login and Registration:** User access to the portal.
- **AI Event Designer:** Supports event stage design and visualization.
- **Event Planner Workspace:** Helps organize event requirements and equipment.
- **Online Services:** Provides access to service-related operations such as Aadhaar, PAN, and financial services.
- **Approval Management:** Supports request review and approval workflows.
- **Analytics Dashboard:** Displays project and operational information.
- **Admin Dashboard:** Provides administrative features.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Browser Local Storage and Session Storage
- REST API integration

## Project Structure

The project contains frontend pages, shared JavaScript functionality, backend server code, and configuration files.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the required Node.js dependencies.
4. Configure the required API keys using the provided `.env.example` file.
5. Start the Node.js server using the project's configured start command.
6. Open the application in your browser using the local server address.

## Important Note

This project was developed for academic and demonstration purposes.

Authentication and browser-based storage are implemented on the client side and are not suitable for production use. Do not enter real passwords or sensitive personal information.
